# survey-data-investigation
An exploratory data analysis project using the Stack Overflow Developer Survey dataset to investigate salary, work experience, job satisfaction, and remote work.

## Project Overview

This project analyses the Stack Overflow Developer Survey dataset to explore relationships between annual salary, work experience, job satisfaction, and remote work arrangements.

## Objectives

* Analyse the distribution of annual salaries.
* Explore the relationship between work experience and salary.
* Understand job satisfaction patterns.
* Compare job satisfaction across different work arrangements.
* Estimate a 95% confidence interval for mean annual salary.

## Tools and Technologies

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SQL

## Project Workflow

1. Load and inspect the dataset.
2. Clean and prepare the relevant data.
3. Perform exploratory data analysis (EDA).
4. Create visualisations.
5. Calculate a 95% confidence interval for mean annual salary.
6. Document the findings and conclusion.

## Key Findings

The analysis explores salary differences across experience levels, job satisfaction ratings, and differences in satisfaction across work arrangements. The exact findings are documented in the Jupyter Notebook.

## Conclusion

This project demonstrates how data analysis and visualisation can help identify patterns in compensation, experience, and employee satisfaction. The results show associations in the survey data and should not be interpreted as proof of cause and effect.
